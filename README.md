# Mecânica Aimoré — Site Institucional

Site demonstrativo desenvolvido para a **Mecânica Aimoré**, com o objetivo de apresentar os serviços automotivos e facilitar o contato com clientes.

🔗 **Acesse o site:** https://thomazalves01.github.io/mecanica-aimore/

## 🚗 Sobre o projeto

O site foi desenvolvido com foco em simplicidade, design moderno e navegação intuitiva, permitindo que os visitantes conheçam a oficina e entrem em contato diretamente pelos canais digitais.

## ✨ Funcionalidades

- Apresentação institucional da oficina.
- Seção de serviços automotivos.
- Galeria de imagens.
- Botão de contato direto pelo WhatsApp.
- Acesso ao Instagram.
- Layout responsivo para celulares e computadores.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Acesso

O projeto está hospedado gratuitamente pelo GitHub Pages.

**Site:** https://thomazalves01.github.io/mecanica-aimore/

## 📌 Observações

Este projeto é uma demonstração de site comercial. Informações, serviços e imagens devem ser confirmados e personalizados com a empresa antes da publicação definitiva.
